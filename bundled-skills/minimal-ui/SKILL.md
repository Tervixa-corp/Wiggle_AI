# Minimal Monochrome UI Discipline

1. Use only flat solid fills (`#0A0A0A`, `#111111`, `#171717`, `#1F1F1F`) and `1px solid #222222` dividers.
2. Never use `linear-gradient`, `radial-gradient`, `conic-gradient`, neon glows, or oversized rounded corners (`<= 4px` inputs/buttons, `<= 6px` modals).
3. Keep typography crisp (`Inter` 13px UI, `JetBrains Mono` 12.5px code) with high-contrast `#EDEDED` primary text.
