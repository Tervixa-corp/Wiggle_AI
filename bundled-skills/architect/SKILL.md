# Architecture Planning

1. Map workspace entry points, crate/package boundaries, and state ownership.
2. Identify shared contracts (types, IPC schemas, API routes) before proposing edits.
3. Produce a concise step-by-step plan with exact file paths, verification steps, and rollback notes.
